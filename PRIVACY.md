# Privacy policy

Go AI Engineering Kit Guide is published by Haniyeh Nasseri. It is a skill-only plugin containing instructions and reference documentation. It has no MCP server, external app, analytics endpoint, or publisher-operated data storage. The plugin does not send chats or files to the publisher.

ChatGPT processes conversations under the user's applicable OpenAI terms and privacy settings. This policy does not replace OpenAI's policies.

Support takes place through public GitHub Issues. Any information users voluntarily post there is public and processed by GitHub. The publisher can see those issues. Avoid posting secrets, private code, or personal information. Users can contact the publisher through an issue about removal of information they posted; GitHub controls its own hosting and retention.

The publisher does not sell conversation data or receive it through the plugin.
