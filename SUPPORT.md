# Support

Go AI Engineering Kit Guide is published by Haniyeh Nasseri.

For questions, documentation corrections, installation guidance, or bug reports, [open a GitHub issue](https://github.com/haniyehnasseri/go-ai-engineering-kit-guide/issues/new).

Include the kit version, agent platform, and a minimal description of the problem. Do not include passwords, API keys, tokens, private source code, or personal information. Issues are public.

Support is community based; no response-time commitment is offered.
